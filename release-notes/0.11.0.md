0.11.0 测试版更新

- 新增 远程访问按 LynShen 账号连接：同一账号的手机和网页可以请求连接这台电脑，在桌面端核对校验码后允许；配对码仍可用（设置 → 远程访问）
- 新增 手机网页登录账号后列出你的电脑，也能操作排队消息、查看 TUI、看交付的图片和视频、管理定时任务
- 新增 排队的消息可以插入当前回合、撤回、删除、拖动排序，或中断后发送（⌘↵ / ⌘⇧↵）
- 新增 从任意一轮分叉对话，可以在新 worktree 中进行，并把结论带回原对话
- 新增 新对话先选项目；标题栏的项目菜单显示分支和改动，可以提交、推送、拉取
- 新增 一轮结束后折叠成一行，显示用时和改动的文件，并列出交付的图片、视频、文件和定时任务提议
- 新增 工具调用显示状态和用时；一轮结束后仍在运行的子智能体和命令显示为「后台任务运行中」
- 新增 Claude Code、Codex 可以添加自己的服务商；内置 OpenCode、oh-my-pi、Pi 智能体；发第一条消息前就能选模型
- 新增 对话的 TUI 可以在其他窗口和手机上查看
- 新增 定时任务显示运行记录，可设单次花费上限、在独立 worktree 中运行；连续失败 3 次自动停用并提示
- 新增 Claude Code 订阅额度提示写明已用多少、何时重置，可以在重置后自动继续
- 新增 开发服务器启动时右下角提示，可以在内置浏览器打开
- 新增 Mermaid 图表、界面缩放（⌘+ / ⌘- / ⌘0）、自选字体和配色、提示音、输出速度统计
- 新增 文件链接右键菜单，可以在外部编辑器打开；任意文件可以作为附件发送，拖到窗口任意位置即可添加
- 优化 余额显示总额，赠送部分写在括号里
- 优化 移除回合、改动、诊断三个面板，本轮改动的文件在对话里查看
- 优化 macOS 上普通鼠标滚轮平滑滚动；引擎中途退出时这一轮标为未完成，可以继续
- 修复 关闭终端时窗口卡住；重启应用后不能再回退之前的轮次
- 修复已知问题
（内置 LynShen CLI 0.8.0）
